# 问题清单与议题树

## 一、核心问题
如何围绕 AI教育培训主线，构建一个可持续积累、可用于直播展示、可用于课程交付、并能逐步形成商业闭环的知识库底座与业务系统？

## 二、一级问题

### 1. 用户与课程问题
- 目标用户是谁？
- 家长和孩子如何共同使用？
- 如何根据物理年龄、AI年龄、能力状态进行分层？
- 如何形成课程地图与选课机制？

### 2. 知识库结构问题
- 知识库的主结构如何设计？
- 如何围绕课程地图组织内容？
- 如何切分为总库、教学库、学员子库？
- 如何进行权限控制与内容开放范围管理？

### 3. 内容采集与加工问题
- 哪些内容进入知识库？
- 哪些内容来自课程、书籍、视频、网页、微信、个人札记？
- 如何将内容转为 Markdown 并做切片、清洗、标注、引用？
- 哪些步骤自动化，哪些步骤人工完成？

### 4. 教学与展示问题
- 如何把知识库变成直播中的展示能力？
- 如何沉淀案例与教学成果？
- 如何通过内容输出反向促进获客与信任建立？

### 5. 用户需求研究问题
- 家长和孩子真正的焦虑是什么？
- 哪些需求值得优先解决？
- 如何通过评论、视频、公开讨论提炼痛点？
- 如何把外部需求转成课程与知识库选题？

### 6. 商业闭环问题
- 如何在 3 个月内形成初步启动与见效？
- 先靠什么变现：直播、课程、一对一还是案例服务？
- 后续如何扩展为小班课、会员、硬件软件推荐、合伙模式？

## 三、优先级排序
当前优先级建议如下：
1. 知识库结构问题；
2. 用户与课程问题；
3. 内容采集与加工问题；
4. 用户需求研究问题；
5. 教学与展示问题；
6. 商业闭环问题（首版先做最小闭环）；

## 四、当前结论
目前项目不缺方向，缺的是主线约束、问题优先级和可复用文档体系。
因此，应优先把问题池整理清楚，再进入专题研究，而不是直接同时做多条支线。

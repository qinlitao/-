
# DeepSeek V4 Pro 调用指南（Claude Code 开发者模式）

## 适用场景
| 任务类型 | 推荐使用 | 注意事项 |
|----------|----------|----------|
| 代码生成 | ✅ 优先 | 提供完整上下文和约束 |
| 代码调试 | ✅ 优先 | 附上错误信息和复现步骤 |
| 架构设计 | ⚠️ 配合 Claude 使用 | 复杂设计先由 Claude 出方案 |
| 文档撰写 | ✅ 可用 | 中文文档效果良好 |

## Prompt 最佳实践

### 结构化输入模板
```text
你是一个执行层编程助手。严格按以下要求完成任务：

【任务】[具体任务描述]
【约束】
- 只修改 [指定文件/函数]
- 不添加未要求的功能
- 匹配现有代码风格
【验证方式】[如何确认完成]
【禁止事项】
- 不重构无关代码
- 不添加过度抽象
```

## 与 Claude Sonnet 4.6 的分工
- Claude（本空间）→ 出方案、出注释、审计结果
- DeepSeek（Claude Code）→ 执行代码、文件操作
- 你（用户）→ 提想法、确认方案、触发执行

# GPT Image 2.0 绘本成功案例库

这个仓库是按“检索使用”设计的 GPT Image 2.0 绘本提示词集合，重点不是泛化模板，而是可直接复用或二次改造的成功案例风格写法。

## 分类
- 01-character-anchors：角色锚点图
- 02-covers：封面案例
- 03-interior-pages：内页案例，含睡前、科普、节日、社交情绪、成长冒险
- 04-edit-continuations：连续编辑案例
- 05-style-locks：风格锁定案例
- 06-consistency-rules：一致性约束案例

## 每个案例字段
- case_id
- use_case
- prompt
- why_it_works
- replaceable_variables
- fix_lines
- tags

## 检索建议
先按题材检索，再按页面类型检索，最后按风格关键词和年龄段过滤。

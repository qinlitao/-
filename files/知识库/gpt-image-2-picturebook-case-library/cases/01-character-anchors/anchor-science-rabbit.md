# PB-ANCHOR-002 科普兔子角色锚点

- case_id: PB-ANCHOR-002
- use_case: 为科普启蒙绘本建立清晰、可教学的儿童角色锚点。
- tags: 角色锚点, 科普启蒙, 6-10岁, 图解, 简洁

## prompt
Create the reusable main character for an educational children’s picture book.

Character:
An 8-year-old rabbit child named Nono, bright curious eyes, soft white fur, pink inner ears, small round glasses, practical explorer vest, green shorts, yellow notebook clipped to a belt.

Purpose:
This character will appear across a science picture book series and must remain visually stable and easy for children to recognize.

Style:
Bright educational picture book art, clean readable shapes, soft ink outlines, gentle color blocking, child-friendly design, not hyper-realistic, not anime.

Composition:
Full body character sheet style, front-facing with slight three-quarter turn, plain pale background, clear silhouette.

Constraints:
Keep the glasses, vest, shorts, and notebook as identity anchors.
No background clutter.
No extra props beyond one pencil.
No text, no watermark.

## why_it_works
- 教学角色更强调 readable shapes 和 clean silhouette，方便知识页复用。
- 把 glasses、vest、notebook 定成识别锚点，有利于不同知识主题下保持人物一致。

## replaceable_variables
- rabbit child -> fox child / bear child
- explorer vest -> lab apron / raincoat / school uniform
- educational -> nature / astronomy / machine / biology

## fix_lines
- Preserve the same clean educational picture book style.
- Keep the notebook and glasses exactly the same.

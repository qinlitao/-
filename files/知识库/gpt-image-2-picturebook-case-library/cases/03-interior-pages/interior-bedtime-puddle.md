# PB-INNER-001 睡前雨后水坑页

- case_id: PB-INNER-001
- use_case: 睡前故事内页，安静发现时刻。
- tags: 内页, 睡前故事, 水彩, 安静, 3-8岁

## prompt
Continue the children’s picture book using the same main character from the reference image.

Scene:
The same little hedgehog girl kneels beside a large rain puddle at dawn and sees the sky reflected like a tiny lake.
She reaches one paw toward the water while holding her acorn satchel close with the other paw.

Character consistency:
Same round face, same warm brown eyes, same chestnut spines, same cream muzzle, same mustard-yellow raincoat, same teal rain boots, same proportions, same gentle personality.
Do not redesign the character.

Style:
Children’s picture book illustration, watercolor and gouache, soft storybook textures, warm quiet atmosphere, readable shapes, suitable for ages 3-8.

Composition:
Medium shot, eye level, character slightly off-center, wide puddle reflection visible, soft early morning light, uncluttered background.

Constraints:
Keep everything child-friendly and emotionally safe.
No horror, no heavy contrast, no extra clothing changes, no new props except small pebbles and raindrops.
No text, no watermark.

## why_it_works
- 这种页的成功关键是把“同一角色”重复写清楚。
- medium shot + uncluttered background 有助于营造睡前页的平静感。

## replaceable_variables
- rain puddle -> moonlit pond / snow reflection / window reflection
- dawn -> twilight / rainy evening

## fix_lines
- Preserve the same outfit and face exactly.
- Keep the atmosphere soft and uncluttered.

# PB-INNER-005 成长冒险跨石头页

- case_id: PB-INNER-005
- use_case: 成长冒险绘本中的小挑战页面。
- tags: 内页, 成长冒险, 轻挑战, 6-9岁, 水彩

## prompt
Create a children’s picture book adventure scene for ages 6-9.

Scene:
The same hedgehog girl carefully crosses a line of wet stepping stones over a shallow stream in the forest.
She looks nervous but determined.
A friendly bird watches from a branch nearby.

Character consistency:
Keep the same face shape, chestnut spines, cream muzzle, mustard-yellow raincoat, teal rain boots, and acorn satchel.

Style:
Watercolor storybook illustration, gentle adventure tone, readable action, soft natural environment, emotionally safe.

Composition:
Medium-wide action scene, stepping stones forming a visual path, character in mid-step, stream visible but not dangerous, enough space for text in one corner.

Constraints:
The scene should feel adventurous but safe for children.
No dramatic peril.
No dark storm.
No realistic danger.
No watermark.

## why_it_works
- 冒险页最容易画成危险场景，所以 safe for children 和 no dramatic peril 必须明确。
- stepping stones forming a visual path 对翻页阅读很友好。

## replaceable_variables
- stepping stones -> rope bridge / hill path / moon ladder
- friendly bird -> firefly / rabbit / robot helper

## fix_lines
- Keep the challenge gentle and visually safe.
- Show determination, not panic.

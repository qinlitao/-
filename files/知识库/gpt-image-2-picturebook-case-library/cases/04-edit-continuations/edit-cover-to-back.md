# PB-EDIT-002 从封面延续到封底

- case_id: PB-EDIT-002
- use_case: 保持封面风格生成封底。
- tags: 连续编辑, 封面到封底, 系列一致性

## prompt
Create the back cover illustration for the same children’s picture book.

Scene:
The little hedgehog girl walks home along the rainy forest path at night, now calm and confident, seen from behind at a slight angle, holding a softly glowing lantern.
The forest feels safe and quiet.

Style:
Same watercolor and gouache storybook style as the cover and interior pages, same palette, same brush softness, same gentle emotional tone.

Composition:
Simple uncluttered vertical back cover, lower visual density than the front cover, generous negative space for back-cover text placement.

Constraints:
Keep exact character identity and costume.
No new dramatic elements.
No extra characters in the foreground.
No watermark, no printed text.

## why_it_works
- 封底通常需要 lower visual density 和 negative space，方便后期排版。
- same palette, same brush softness 能显著减少封面与封底断裂。

## replaceable_variables
- rainy forest path -> village street / snowy lane / hallway home
- softly glowing lantern -> flashlight / star jar / paper moon

## fix_lines
- Match the same palette and brush texture as the cover.
- Reduce visual density and preserve empty space.

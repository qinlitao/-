- tags: 风格锁定, 科普图解, 教育, 6-10岁

## prompt
Create the image in a bright educational picture book style with simple infographic clarity.

Style requirements:
Clean shapes, soft outlines, clear visual hierarchy, balanced labels space, child-friendly educational tone, natural but bright palette, readable cutaway structure, uncluttered composition.

Avoid excessive decoration, dramatic cinematic darkness, painterly ambiguity, dense tiny details, and adult technical illustration tone.

## why_it_works
- 这类风格词比单纯写“科普风”更具体，能压住无关装饰。
- readable cutaway structure 对结构类页面特别有帮助。

## replaceable_variables
- cutaway structure -> diagram spread / comparison layout / life cycle sequence

## fix_lines
- Prioritize clarity and simple educational readability.
- Reduce decorative details and make the structure clearer.

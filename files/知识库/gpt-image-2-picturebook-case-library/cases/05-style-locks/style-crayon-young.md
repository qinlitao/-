# PB-STYLE-003 蜡笔儿童手绘风格锁定

- case_id: PB-STYLE-003
- use_case: 低龄段绘本的蜡笔手绘风格。
- tags: 风格锁定, 蜡笔, 3-6岁

## prompt
Create the image in a childlike crayon picture book style.

Style requirements:
Visible crayon texture, slightly uneven coloring, simple shapes, thick friendly outlines, bright basic colors, spontaneous feeling, suitable for ages 3-6.

Avoid realistic shading, complex perspective, tight polished rendering, or adult comic styles.

## why_it_works
- 对 3-6 岁来说，这种风格更贴近“孩子自己画”，有代入感。

## replaceable_variables
- crayon -> colored pencils / marker doodles

## fix_lines
- Keep the crayon texture obvious and childlike.
- Avoid polished realistic rendering.

# PB-STYLE-001 温暖水彩风格锁定

- case_id: PB-STYLE-001
- use_case: 给整本绘本锁定温暖水彩风。
- tags: 风格锁定, 温暖水彩, 全书统一

## prompt
Create a children’s picture book illustration in a warm watercolor-and-gouache storybook style.

Style requirements:
Soft brush edges, transparent layered washes, warm paper texture, gentle natural color transitions, friendly facial expressions, clean silhouettes, readable compositions for children.

Use this style consistently across cover and interior pages.
Avoid hyper-realism, glossy 3D rendering, anime styling, harsh outlines, overly saturated neon colors, and dark horror mood.

## why_it_works
- 风格锁定语句适合叠加到各类页面 prompt 里，作为统一尾段。
- 同时写正向风格和反向限制，更容易稳定输出。

## replaceable_variables
- warm watercolor-and-gouache -> collage cut-paper / pastel crayon / flat educational graphic

## fix_lines
- Preserve the same warm watercolor storybook texture.
- Avoid switching to digital glossy or anime rendering.

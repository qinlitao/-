# 检索调用指南

## 推荐检索维度
1. 按页面类型：角色锚点 / 封面 / 内页 / 连续编辑 / 风格锁定 / 一致性规则
2. 按题材：睡前故事 / 科普启蒙 / 节日主题 / 社交情绪 / 成长冒险
3. 按年龄：3-5 / 6-8 / 9-12
4. 按风格：水彩 / 拼贴 / 粉彩 / 扁平 / 科普图解 / 轻奇幻发光

## 推荐调用方式
请从案例库中检索与“{主题}”最接近的 {题材} + {页面类型} + {风格} 案例，保留它的写法结构，只替换主角、场景、教育目标和视觉锚点，生成适配 GPT Image 2.0 的最终提示词。

## 连续出图调用方式
请先检索角色锚点案例，再检索对应题材的内页案例，最后叠加一致性规则与连续编辑案例，输出可连续生成 12 页绘本的提示词包。

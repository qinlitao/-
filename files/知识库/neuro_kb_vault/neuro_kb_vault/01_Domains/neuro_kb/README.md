# neuro_kb

## Domain Name

类人脑知识库

## Scope

本领域当前收录的是“科学减肥”相关资料，不按原文逐段搬运，而是按 Fact、View、Episode、Procedure、Task 五类对象进行提炼与组织。

## Subdomains

- `weight_management/social_support`
- `weight_management/pharmacotherapy`
- `weight_management/bariatric_surgery`
- `weight_management/intervention_framework`

## Curation Principles

- 优先沉淀经过加工、未来可复用的结论与方法。
- 一句话同时包含事实和观点时，拆为 Fact 与 View。
- 任务型问题使用 Task 作为入口，并通过关系连接相关对象。
- 权重、QA 评分与关系边使用外置文件维护。

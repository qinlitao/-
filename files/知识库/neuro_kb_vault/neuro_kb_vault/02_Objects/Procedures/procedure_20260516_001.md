# 构建减肥社交圈的执行流程

## Goal

把减重从个人单打独斗，转成由家庭、朋友和社群共同支撑的持续行动系统。

## Steps

1. 先选一度圈层标杆，优先考虑伴侣、父母或共同生活者，判断他们是否能在饮食采购、烹饪、作息和日常提醒上形成支持。
2. 再选二度支持者，从朋友、同事、室友、饭搭子中至少找两位，要求他们愿意一起吃减脂餐、一起运动或一起拒绝高风险场景。
3. 如果身边支持不稳定，就补上三度社群，选择减重 App、小群或长期活跃社群，重点不是热闹，而是持续陪伴与可见反馈。
4. 对所有与减重有关的行为做“浸染式安排”，比如吃、动、睡、压力管理，都尽量与标杆或社群一起发生。
5. 固定做主动输出，周期性分享进展、失败、困惑与心得，让自己也成为可被监督和可被模仿的人。
6. 每两周复盘一次社交圈质量，淘汰只制造诱惑或频繁失约的连接，强化稳定支持源。

## Notes

- 这套流程的关键不在“找很多人”，而在“找能稳定影响日常行为的人”。
- 线上社群可作为补位，但应避免只打卡、不改变行为的空转模式。
- 主动分享既是外部监督机制，也是自我身份强化机制。

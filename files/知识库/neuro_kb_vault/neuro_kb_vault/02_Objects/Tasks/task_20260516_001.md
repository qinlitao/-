# 为肥胖干预对象选择合适路径

## Goal

判断一个具体对象当前更需要优先强化生活方式与社交支持，还是已经进入需要评估药物或手术干预的阶段。

## Constraints

- 不能把药物或手术当作默认起点。
- 需要结合 BMI、并发症、执行环境和长期维持能力。
- 需要先判断其是否缺乏基本支持环境。

# 区分保健品、正规减肥药与具有减肥副作用的药物

## Goal

在面对市场上各种“减肥产品”时，先做基本分类，再决定是否进一步评估。

## Constraints

- 不能把保健品、处方药、降糖药和来路不明产品混为一谈。
- 需要先判断它的原始用途，而不是只看“能不能减重”。
- 一旦出现来源不明、明显副作用或特殊生理阶段，应优先停止自我决策并回到医生评估。

## Evidence

- 课程一开始就将相关产品分成三类并分别讨论。
- 评论区中的左旋肉碱、酵素、微商减肥药和二甲双胍问题都说明分类先行很重要。

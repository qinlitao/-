# 代餐

## 医学定义

为减肥或维持减肥效果而开发的，**代替一天中一顿或两顿饭**的食物产品。

> 注意：一天三顿全吃代餐 = 全配方代餐(RCD)，属医疗级，需医生处方监测。

## 代餐效果（LOOK AHEAD研究，n=5145，历时10年）

| 时间 | 与对照组差距 |
|------|-------------|
| 1年 | -7.7 kg |
| 2年 | -5.2 kg |
| 4年 | -3.4 kg |

## 挑选合格代餐的两条标准

1. **能量**：150–350大卡/顿，且比例合理
   - 碳水 ≤ 40%
   - 蛋白质 20%–30%
   - 脂肪 ≤ 30%（饱和脂肪酸 ≤ 10%）
2. **微量元素**：维生素A/B/C/D/E/K + 钙铁锌纤维素齐全

## 代餐效果最大化公式

```
代餐  +  饮食调整  +  合理运动  =  最大减肥效果（7.7kg/年）
```

## 注意事项

- 代餐期间两餐之间**不能吃任何有热量的食物**
- 未养成健康生活方式前，代餐**不能停**
- 无法增强体质或延年益寿，仅为减肥工具

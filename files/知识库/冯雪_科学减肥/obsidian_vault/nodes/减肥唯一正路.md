# 减肥唯一正路

## 核心论点

**生活方式干预**是全球科学家公认的首选减肥方法（最有效、最安全、最省钱）。

## 肥胖成因链条

```
基因 + 社会环境 + 心理因素
        ↓
    不健康生活方式（直接原因）
        ↓
       肥胖
```

## 为什么其他方法都失败？

| 方法 | 问题 |
|------|------|
| 单纯节食 | 打破水箱平衡 → 基础代谢下降 + 10倍饥饿感 |
| 单纯运动 | 压力不解决，需4–5倍运动量 |
| 减肥药 | 效果有限，副作用大，需配合生活方式 |
| 减肥手术 | 不改变生活方式仍会反弹 |

## 生活方式三要素

- [[饮食选择]]
- 运动管理
- 心理管理（压力 + 睡眠）

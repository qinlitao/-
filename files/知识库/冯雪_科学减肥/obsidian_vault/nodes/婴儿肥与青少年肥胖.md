# 婴儿肥与青少年肥胖

## 核心结论

> **没有"婴儿肥"，没有"青春肥"。** 18岁之前胖，后半辈子大概率继续胖。

## 儿童肥胖判断标准（WHO）

通过BMI对照同性别同年龄百分位数：
- 超过**85th**百分位线 → 超重
- 超过**97th**百分位线 → 肥胖

## 儿童肥胖的三大危害

1. **不长个**：脂肪细胞过多 → 内分泌失调 → 骨骺线提早闭合
2. **一胖一辈子**：
   - 肥胖儿童成年后继续肥胖概率：42%–63%
   - 肥胖青少年成年后继续肥胖概率：70%–80%
   - 根本原因：**脂肪细胞数量成年后固定不变，只有大小变化**；脂肪细胞还有"记忆"功能
3. **心理健康受损**：易被戏弄→不合群→以食物慰藉→恶性循环

## 预防儿童肥胖十招（精选）

| 招数 | 要点 |
|------|------|
| 统一家庭认知 | 全家人都了解肥胖危害 |
| 孕前控重 | 父母双方都胖→孩子肥胖风险4倍 |
| 新生儿体重 | 正常范围2.5–4公斤（不走两端） |
| 母乳喂养 | 至少1周岁，降低肥胖风险15%–20% |
| 限制果汁 | 果汁是儿童肥胖重灾区 |

## 脂肪细胞的"记忆"

成年前（婴幼儿→青春期）是脂肪细胞唯一生长期。此阶段若受营养刺激（过饥或过饱），脂肪细胞会永久"记住"并终身倾向囤积能量。

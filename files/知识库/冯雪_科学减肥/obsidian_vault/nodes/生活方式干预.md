# 生活方式干预

全球科学家公认的**首选减肥方法**，因其最有效、最安全、最省钱而被推荐。

> 科学减肥的方法只能是健康生活方式的养成。生活方式调整就是减肥的阳关大道。

## 三角形结构（三条边缺一不可）

```
         饮食
        /    \
    运动 ———— 心理管理
       （压力 & 睡眠）
```

## 两个常见误区

1. **误区一**：生活方式调整起效慢、性价比低
   - 真相：无法应对压力的人，需要4–5倍运动量才能达到同等减肥效果
2. **误区二**：健康生活方式太难，做不到
   - 真相：坚持21天后习惯固化，身体会自动倾向健康食品

# 能量缺口理论

科学减肥的**第一性原理**：减肥的本质是制造**能量缺口**（能量摄入 < 能量消耗）。

## 水箱模型

身体如同一个水箱：
- 进水 = 饮食摄入热量
- 出水 = 基础代谢 + 运动消耗
- 水位 = 体重/脂肪量

> 只从单一水龙头强硬干预（纯节食/纯运动），会打破系统平衡，导致基础代谢下降、饥饿感10倍增加，最终**体重反弹**。

## 正确做法

同时调整饮食、运动、睡眠、压力管理，形成**每日500–750大卡**的能量缺口。

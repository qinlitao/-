# 饮食选择

## 挑选食物的四个黄金准则

| 准则 | 说明 |
|------|------|
| 加工越少越好 | 选新鲜食材；火锅 > 炒菜 > 油煎 > 油炸 |
| 食物越完整越好 | 不削皮、不榨汁；选全麦、糙米 |
| 脂肪选天然不饱和 | 植物油、深海鱼、坚果；**坚决不吃反式脂肪酸** |
| 蛋白质越纯越好 | 优先：鱼 > 禽 > 瘦肉；每公斤体重≥1g蛋白质/天 |

## 2-1-1 餐盘模型

```
┌─────────────────────┐
│  蔬菜水果（1/2）     │  约半斤蔬菜 + 4两水果
├──────────┬──────────┤
│ 全谷物主食│  瘦肉/豆  │  各占1/4
│  （约3两）│ 制品(约2两)│
└──────────┴──────────┘
```

## 一日三餐要点

- **早饭必须吃**（不吃早餐 → 体重增加）
- **晚饭不超过9点**（建议8点刷牙）

## ⚠️ 反式脂肪酸危害

1. 黏附血管，心脑血管疾病风险+50%
2. 增加腹部肥胖（内脏脂肪）
3. 几乎无法通过运动代谢

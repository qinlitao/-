# BMI（体重指数）

BMI 是衡量肥胖程度的标准医学指标，计算公式：

**BMI = 体重(kg) ÷ 身高(m)²**

## 成人分级标准（中国标准）

| BMI 范围 | 分类 |
|----------|------|
| < 18.5 | 体重过轻 |
| 18.5–23.9 | 正常体重 |
| 24–27.9 | 超重 |
| ≥ 28 | 肥胖 |

## 医疗决策阈值

| BMI | 推荐干预方式 |
|-----|-------------|
| ≥ 27 + 并发症 | 可考虑[[减肥药物]] |
| ≥ 30 | 可考虑[[减肥药物]]（无并发症） |
| ≥ 35 + 严重糖尿病 | 推荐[[减肥手术]] |
| ≥ 40 | 强烈推荐[[减肥手术]] |

## 儿童/青少年 BMI
- 与同性别同年龄段对照
- 超过 85th 百分位 → 超重
- 超过 97th 百分位 → 肥胖
- 详见 [[婴儿肥与青少年肥胖]]

## 局限性
BMI 无法区分[[内脏脂肪]]与皮下脂肪，腰围是更好的腹型肥胖指标。

# 代餐

代替一天中一顿或两顿正餐的食品产品，经大量研究证实**有效、安全**，美国/加拿大/英国糖尿病指南均推荐。

## 有效性证据（LOOK AHEAD研究，5145人，10年）

| 时间节点 | 代餐组 vs 非代餐组减重差距 |
|----------|--------------------------|
| 1年后 | **-7.7 kg** |
| 2年后 | -5.2 kg |
| 4年后 | -3.4 kg |

**且同时可降低体脂率、减小腰围（塑形效果）**

## 挑选代餐两条核心标准

### 标准一：能量合理（150–350大卡/份）
| 营养素 | 比例要求 |
|--------|---------|
| 碳水化合物 | ≤ 40% |
| 蛋白质 | 20%–30% |
| 脂肪 | ≤ 30%（饱和脂肪 < 10%） |

> ❌ 纯酵素、15g小饼干、宣称饱腹1小时的代餐棒：能量不达标，不算真代餐

### 标准二：维生素和微量元素充足
- 必含：维生素 A/B1/B2/B6/B12/C/D/E/K
- 必含：钙、铁、锌、镁、膳食纤维
- **特别注意 B 族维生素**（缺乏→脱发、口腔溃疡）
- 坚果棒/酸奶杯不能提供足够矿物质，不算合格代餐

## 最大化效果公式

```
单纯代餐：比饮食限制多减 +1.44 kg/年
代餐 + 营养管理：多减 +3.87 kg
代餐 + 营养管理 + 运动：多减 +6.13 kg
vs 普通减肥者：多减 +7.7 kg
```

## 使用规则
1. 代替 **1–2顿**正餐（三餐全代 = 全配方RCD，需医生处方）
2. 代餐期间**不能再吃**其他有热量的食物（否则变零食）
3. 没有合并营养性疾病（糖尿病、肾病等）才可自行使用
4. 在养成[[生活方式干预]]前，**代餐不能停**（停了必反弹）

## 价格与品牌
- 不同品牌原材料基本相同（以吨为单位批量购买）
- 不需要购买溢价产品，**物美价廉即可**

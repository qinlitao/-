# 减肥手术

2013年全美医学创新榜首，2015年十年医学创新第三位。不仅能减肥，还能逆转90%的2型糖尿病。

## ⚠️ 重要区分：抽脂术 ≠ 减肥手术

| | 抽脂术 | 减肥手术 |
|--|--------|---------|
| 目的 | 局部塑型（美容） | 减重、改善代谢 |
| 去除脂肪类型 | 皮下脂肪 | 通过缩胃减少[[内脏脂肪]] |
| 持久性 | 3个月后反弹回内脏 | 12年随访仍有效 |
| 科室 | 整形外科 | 外科/代谢科 |

## 三种主要术式

| 术式 | 原理 |
|------|------|
| 胃旁路手术 | 用小肠在胃旁边做通路，胃闲置 |
| 袖状胃切除 | 直接切除部分胃 |
| 胃内球囊 | 在胃内放可充气球囊，缩小容积 |

## 长期效果（12年随访）
- 93% 的患者体重仍比术前轻 10%
- 40% 的患者比术前轻 30%
- **90% 的2型糖尿病实现临床缓解**

## 手术起效的三个层次

### 物理层
胃容积变小 → 食物通过加快 → 消化吸收减少 → [[能量缺口]]自然形成

### 化学层
- **胆汁酸↑** → 改变肠道菌群 → 改变味觉（更接受蔬果，排斥糖脂）
- **胰高血糖样肽↑** → 减缓胃排空 → 减饥饿感 + 促胰岛素分泌 → 缓解糖尿病

### 神经层
菌群+激素信号 → 神经传导至大脑 → 降低食欲 → 减少能量摄入

## 适用人群
- [[BMI]] ≥ 40 → 强烈推荐
- [[BMI]] ≥ 35 + 严重2型糖尿病 → 推荐
- [[BMI]] < 35 → 暂无充分数据，不推荐

## 注意事项
- 手术后**仍需**改变[[生活方式干预]]，否则效果不稳固
- 手术有一定副作用风险，并非人人适合

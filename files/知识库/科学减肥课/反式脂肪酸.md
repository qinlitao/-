# 反式脂肪酸

反式脂肪酸是减肥（乃至健康）的**绝对禁区**，即使减量也不建议摄入。

## 三大恶性危害
1. **黏附血管壁** → 心脑血管疾病风险 +50%
2. **黏附内脏脂肪** → 增加腹部[[内脏脂肪]]
3. **极难代谢** → 无论怎么运动和节食，依然堆积体内

## WHO 的明确立场
2018年，WHO 正式要求全球食品行业在未来5年内**消灭**反式脂肪酸添加。

## 常见来源（需警惕）

| 食品类型 | 反式脂肪酸来源 |
|----------|---------------|
| 蛋糕、面包、饼干 | 起酥油、人造黄油 |
| 冰淇淋 | 人造植物油 |
| 油炸食品 | 氢化植物油 |
| 奶茶甜品 | 人造奶油、人造可可脂 |

## 如何识别（食品标签）
- 查看**脂肪栏**中"反式脂肪酸"含量
- **不为零就不选**
- 配料表中含以下词语需警惕：起酥油 / 人造植物油 / 人造可可脂 / 人造奶油 / 人造黄油

> ⚠️ 注意：标注"0"不代表绝对没有（≤0.3g/100g 可标注为0）

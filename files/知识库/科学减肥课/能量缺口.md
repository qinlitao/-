# 能量缺口

能量缺口是科学减肥的**第一性原理**：当身体消耗的能量持续大于摄入的能量，体重就会下降。

## 目标值
- 安全有效的每日缺口：**500–750 大卡**

## 水箱模型
身体如同一个水箱，能量有进有出维持动态平衡：
- 强行节食 → 打破平衡 → 身体报复性保护脂肪、降低[[基础代谢]]
- 疯狂运动 → 单维度刺激 → 反弹
- 正确做法：从[[饮食四准则]]、运动、心理三方面同步发力

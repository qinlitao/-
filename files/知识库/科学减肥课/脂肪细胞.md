# 脂肪细胞

理解脂肪细胞的特性，是理解为什么"婴儿肥"危险、为什么有人是易胖体质的关键。

## 核心特性

### 1. 数量在成年前固定
- 脂肪细胞**唯一生长期**：婴幼儿期 → 青春期（数量达到顶峰）
- 成年后数量**不增不减**，变化的只是每个细胞的**大小**
- 幼年期营养过剩 → 脂肪细胞数量多 → 成年后更容易胖

### 2. 脂肪细胞有"记忆"
若成年前（脂肪细胞生长期）经历以下任一刺激：
- 长时间饥饿
- 经常吃到特别撑
- 短时间摄入大量高热量食物

→ 身体向脂肪细胞发出**过度生长信号**  
→ 脂肪细胞终生"记住"该信号  
→ 此后一辈子更倾向于囤积能量  
→ 形成**易胖体质**

### 3. 两种脂肪组织
| 类型 | 功能 | 与体重关系 |
|------|------|------------|
| 白色脂肪 | 储存能量（即通常意义的肥胖脂肪） | BMI 正相关 |
| 棕色脂肪 | 产热、消耗能量 | BMI **负相关**（棕色脂肪越多越不易胖） |

> 适度寒冷可促进棕色脂肪细胞增长（"三分饥与寒"的科学依据）

## 对儿童肥胖的启示
- 童年营养过剩 → 脂肪细胞数量永久增多 → 成年后42%–80%会持续肥胖

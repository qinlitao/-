# 饮食四准则

在保持[[能量缺口]]的前提下，通过"学会挑食"科学搭配减肥餐的四条黄金准则。

## 准则一：食材越少加工越好
- 正餐避免深加工成品食物
- 零食/饮料：薯片、饼干、甜品、奶茶几乎都是陷阱
- **烹饪优先级：火锅 > 炒菜 > 油煎 > 油炸**
- 火锅锅底避免牛油，调料避免麻酱（脂肪含量极高）
- 坚持21天，味觉恢复后会自然排斥重加工食物

## 准则二：食物越完整越好
- 蔬菜、水果：能不削皮就不削皮，能不榨汁就不榨汁
- 谷物：选全麦、糙米等粗粮，保留更多纤维素
- 纤维素不被吸收但填饱肚子，减少饥饿感，保留维生素

## 准则三：脂肪选天然不饱和脂肪
- **优选**：植物油（橄榄油、菜籽油、葵花籽油等）、深海鱼、坚果（每天一捧）
- **禁止**：[[反式脂肪酸]]（心脑血管风险+50%，难代谢，增加[[内脏脂肪]]）
- 油温不要过高（冒烟后不饱和脂肪酸被破坏，可能产生致癌物）

## 准则四：蛋白质越纯越好
- 每天每公斤体重补充 **1–1.5克** 蛋白质
- 选择优先级：**鱼虾 > 禽类 > 牲畜瘦肉**
- 推荐10种肉类：鱼肉、虾肉、鸽子肉、兔肉、鸡胸肉、鸭胸肉、驴肉、牛瘦肉、羊瘦肉、猪后腿肉
- 豆制品（植物蛋白）同样推荐

## 餐盘搭配（2-1-1原则）

```
┌─────────────────────────┐
│  蔬果 × ½               │
│  约半斤蔬菜 + 四两水果  │
├──────────┬──────────────┤
│ 全谷物   │ 瘦肉/豆制品  │
│  × ¼     │    × ¼       │
│  ~三两   │   ~二两      │
└──────────┴──────────────┘
```

## 一日三餐要点
- 早饭**必须吃**（不吃早餐 → 体重增加，有科学研究证实）
- 晚饭不超过**晚9点**（技巧：8点刷牙，降低进食冲动）
- 餐数/频率/进食速度对减肥影响不大，自由安排

# 饮食选择：如何保证吃对又不饿？

## 知识卡片

- 在保证每日能量缺口的前提下，通过“学会挑食”来搭配长期可持续的减肥餐。
- 四个黄金准则：少加工、食物完整、选天然不饱和脂肪、优先高纯度蛋白质。
- 日常烹饪推荐“蒸煮炖胜过煎炸”，高度加工零食和含糖饮料是减肥陷阱。
- 注意避开反式脂肪酸，学会读配料表和营养标签是减肥期关键技能。
- 一日三餐结构可用“蔬菜2：主食1：蛋白质1”做基础模板，早餐必须吃，晚餐不宜过晚。
